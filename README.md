# Gabriel M. Morabe – Portfolio

React + Vite + Tailwind CSS (v3). Dark and light themes, content kept in one file.

## Run it
```
npm install
npm run dev
```

## Edit your content
All text, projects, skills and certifications live in `src/data.js`.
Images are in `public/images/`.

To show a "Download CV" button, put a public link to your CV PDF in `cvUrl` in `src/data.js`.

## Deploy
```
npm run build
```
Upload the repo to GitHub, then import it on Vercel or Netlify. Build command `npm run build`, output folder `dist`.
